# Documentos de negocio

Estos documentos describen el negocio que el software debe servir. No sustituyen contratos legales ni una decisión financiera formal.

## Archivos

- `product-brief.md`: producto, usuario y problema.
- `business-model.md`: suscripción, límites, costos y reglas de acceso.
- `go-to-market.md`: mensaje, funnel y sección editorial de incidentes.
- `pricing-inputs.md`: datos que hay que decidir antes de fijar precios.

Regla: no publicar precios, métricas, logos de clientes, certificaciones ni historias de incidentes hasta tener aprobación y fuente verificable.
